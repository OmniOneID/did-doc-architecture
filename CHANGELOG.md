# Changelog

## v3.0.0 (2026-11-13)

### 🚀 Added
- Added OID4VCI-based Credential issuance and revocation (Pre-Authorized Code, Authorization Code and user-initiated issuance)
- Added OID4VP-based presentation and ISO/IEC 18013-5 mdoc proximity presentation
- Added OID4VC Credential data standards (SD-JWT VC format, mdoc format, Credential Status format)
- Added OID4VCI issuance and revocation (P230–P240), OID4VP presentation (P320) and mdoc proximity presentation (P330) sequences
- Added Proxy mode VC issuance (P210)
- Added LSS (Ledger Service Server) as an alternative Trust Repository to the blockchain
- Added OID4VCI Credential lifecycle and local Wallet Token
- Added lectures and tutorials
- Added OpenDID 3.0 and PoC repositories to the repository list
- Added glossary of terms defined in the documents
- Added structure diagrams for SD-JWT VC, mdoc, Status List, ZKP data and Profile

### 🔧 Changed
- Updated Software Architecture and architecture diagrams for OpenDID 3.0
- Fixed typos, broken links and mistranslations across documents
- Replaced sequence source (.puml) links with sequence diagrams in the documents


## v2.0.0 (2025-05-29)

### 🚀 Added
- Added support for Zero-Knowledge Proof (ZKP) functionality and related documentation
- Updated documentation to reflect new repository structure
- Added support for Hyperledger Besu

### 🔥 Removed
- Removed support for Hyperledger Fabric
